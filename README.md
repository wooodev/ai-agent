# 따릉이 물어보기

동네 소식을 쓰는 지역 기자나 구청 자전거 담당자가 "우리 동네 따릉이는
언제, 어디로 많이 가나"를 확인하려면, 하루 20만 행이 넘는 이용 기록 CSV를
직접 열어 집계해야 합니다. 5일치만 합쳐도 126만 행이라 엑셀 행 한도를
넘고, 출발·도착 기록이 이중으로 들어 있어 그냥 합치면 건수가 2배가 됩니다.

이 프로젝트는 서울 따릉이 이용 기록에 **한국어로 질문하면 답과 함께 근거
(실행한 SQL과 결과표)를 보여 주고, 사람이 해석을 고쳐 다시 실행할 수 있게**
합니다.

## 현재 상태

기획 단계 (`v0.1`). 기획서는 [docs/proposal.md](docs/proposal.md).
