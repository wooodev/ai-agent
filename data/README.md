## 컬럼

| 컬럼                              | 뜻                                                          |
| --------------------------------- | ----------------------------------------------------------- |
| 기준\_날짜                        | YYYYMMDD                                                    |
| 집계\_기준                        | 출발시간 / 도착시간. 같은 이용이 두 기준으로 각각 들어 있다 |
| 기준\_시간대                      | HHMM, 5분 단위 (0000 \~ 2355)                               |
| 시작*대여소\_ID / 종료*대여소\_ID | ST-xxxx                                                     |
| 시작*대여소명 / 종료*대여소명     | "행정동*번호*번호" 꼴 (예: 망원1동\_005_2)                  |
| 전체\_건수                        | 이용 건수                                                   |
| 전체*이용*분 / 전체*이용*거리     | 이용 시간(분), 거리(m). 합계인지 평균인지 정의서 확인 필요  |

## 오늘 본 더러움

1. 같은 이용이 출발시간·도착시간 행으로 두 번 들어 있다 (날짜별 합계가 정확히 같음)
2. 대여소명이 실제 이름이 아니다. 구(區) 정보가 없다
3. 대여소명이 빈 행: 시작 1,218행, 종료 6,887행. 특정 ID 5개에 몰려 있고 다른 행에서 복구할 수 없다
4. ID 하나에 이름이 둘인 대여소 2곳 (ST-3428, ST-1485)
5. 이용 시간·거리가 빈 행: 출발 기준 19,063행 (19,311건)
6. 이상값: 이용 시간 600분 초과 81행, 최대 거리 212km. 출발 대여소 = 도착 대여소인 행 약 7.9만 행
7. 비슷한 이름의 동이 여럿 있다 (신사동, 신사1동, 신사2동은 서로 다른 구일 수 있다)
